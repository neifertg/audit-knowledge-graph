| Folder | Purpose | Owns | Entry point |
|---|---|---|---|
| `src/features/generator/` | generates the synthetic US regional bank (organization, ERM and IA taxonomies, risks, controls, audits, issues) plus a hidden answer key, so reconciliation accuracy can be measured. | every entity and relationship in `docs/data-model.md` except the canonical layer (E2); the answer key. | `generate.py` (`build()`); run it with `python -m akg build`. |
