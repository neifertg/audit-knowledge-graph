The Risks section says "AC-4 strips `NEO4J_*` from test subprocesses, and the done-check runs the full suite under `with_neo4j` to prove it". That run does not prove it. unittest discovery runs `tests/generator` and `tests/reconciliation` before `tests/stores`, so a leaked subprocess build reloads Neo4j before the fixture load in `test_neo4j.py`. It takes time but breaks nothing: AC-3 still passes on the fixture's own reload. Better still, route `test_batch` and `test_offline` through one env function (for example `helpers.subprocess_env()`) that this check covers, so new tests cannot leak by forgetting it.
