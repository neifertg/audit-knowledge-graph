# rounds

Purpose: the head-to-head planning rounds, each one question asked in SQL and in Cypher over the same facts, proved by agreement, an oracle and the planted scenario, and exported to `rounds.json` for the page.
Entry point: `runner.py` (`run_rounds()`, `main()`), run by `python -m akg rounds --out <dir>` and as steps 4-5 of `python -m akg build`; `export.py` for the committed `rounds.json`.
Owns: no data entities; the rounds' queries (`roundN.sql`, `roundN.cypher`, round 5's `.setup` files, `owners.*`), the registry (`registry.py`), the measured-verdict rule (`verdict.py`), the oracle (`oracle.py`), round 5's register (`fourth_party.csv`) and the committed export (`rounds.json`).
Depends on: `src/features/stores/` (`akg.sqlite`, the Neo4j graph and its `LoadComplete` checksum); the generator's fictional vendor list; `src/features/reconciliation/weights.json` (its fingerprint is exported).

Notes for people and agents working here:
- **Both sources, both engines.** Neo4j's shared labels merge ERM and IA. SQL gets the same merging from `views.sql` (eight temporary views, including `control` and `owned_by`), made on each connection, never in the store schema and never scored. A round's SQL may name a per-source table only if the registry lists it in `source_tables`.
- **Three checks**: agreement (SQL rows equal Cypher rows), an oracle (`oracle.py`, Python from the CSVs, no answer key) and the scenario (answer key read in the tests only; the export names the verifying test).
- **Round 2's cutoff** is the parameter `:cutoff` / `$cutoff`, default 2023-12-31 in `registry.py`. A control counts as tested when an audit testing it ended on or after it (inclusive). `has_ia_member` marks canonical risks with an IA member; the rest are stale by construction.
- **Round 5's register** is `fourth_party.csv`, regenerated by `python -m src.features.rounds.fourth_party` (`random.Random('fourth-party-v1')`, k from (0, 0, 1) per vendor, fictional names only). The vendor asked about is the one most vendors rely on, ties by name (Ivelle Financial Technology). Its setup runs in a transaction that is always rolled back: a TEMP table on the read-only SQLite connection, and one explicit Neo4j transaction with no schema change. Neo4j keeps new label and type names in its token store; the data is unchanged.
- **Owner concentration** (`owners.*`) is a supporting query: derived, not planted. `LEFT JOIN`s and an `OPTIONAL MATCH` keep key controls that reach no business unit.
- **The Neo4j guard** refuses a graph with no `LoadComplete` node or a checksum other than `reconciled_checksum(<dir>)`. It does not detect a changed `akg.sqlite`.
- **The measured verdict** (`verdict.py`) is symmetric (owner decision, 2026-11-21): each side scores `clauses + steps + 5 * moving_parts`; the side whose score times 1.25 is at most the other's wins, else `close`. A SQL join counts once, as a step (`JOIN` is a layout keyword, not a scored clause); Cypher's `*n` counts n hops; recursion counts once per side; `OPTIONAL MATCH` is a clause. A round with setup is scored as setup plus query. The **margin** is `max - 1.25 * min`; rounds 1, 3 and 7 are within one point of the line. Do not tune the rule to move a verdict.
- **The export**: `akg rounds` writes `<dir>/rounds.json` with whatever engines ran. Regenerate the committed copy with both engines by running `python -m src.features.rounds.export` with Neo4j configured, locally `.venv\Scripts\python -m src.features.stores.with_neo4j -m src.features.rounds.export` (it builds seed 42 itself and replaces the Neo4j database, as every load does). A test fails when the committed copy is stale.
- **Query style** (checked by tests): each clause keyword starts its own line, no line over 100 characters, comments on their own line, no comma joins.
- **A new round:** add `roundN.sql` and `roundN.cypher` (and `.setup` files if it brings new data), a `Round` entry in `registry.py`, its oracle in `oracle.py`, and its entry in docs/data-model.md; then regenerate `rounds.json`.
